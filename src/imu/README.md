# gimbal/src/imu —— IMU 实现（ICM-42688-P over I²C + 俯仰融合）

本目录两个源文件：`imu_i2c.cpp`（寄存器配置/读取，`i2c-dev`）与 `imu_pitch.cpp`（互补滤波融合）。

## 文件一览

| 文件 | 内容 |
|---|---|
| `imu_i2c.cpp` | ICM-42688-P：地址自动识别、寄存器初始化、14 字节脉冲读取、换算 |
| `imu_pitch.cpp` | 俯仰融合：`asin(u·â)` 求加速度角 + 陀螺积分 + 创新门限 + 零位 |

---

## 1. `imu_i2c.cpp` —— 寄存器与读取

### 1.1 用到的寄存器（bank 0）

| 寄存器 | 地址 | 写入值 | 含义 |
|---|---|---|---|
| `REG_BANK_SEL` | 0x76 | 0x00 | 选 bank 0 |
| `PWR_MGMT0` | 0x4E | 0x0F | 陀螺 + 加速度都进低噪声模式 |
| `GYRO_CONFIG0` | 0x4F | 0x04 | ±2000 °/s，200 Hz |
| `ACCEL_CONFIG0` | 0x50 | 0x24 | ±8 g，200 Hz |
| `WHO_AM_I` | 0x75 | 只读 | 应为 **0x47** |
| 数据区 | 0x1D 起 14 B | 只读 | 温度 2 + 加速度 6 + 陀螺 6 |

### 1.2 换算

| 量 | 灵敏度 | 公式 |
|---|---|---|
| 加速度 | 4096 LSB/g（±8 g） | `a_g = raw / 4096` |
| 陀螺 | 16.4 LSB/(°/s)（±2000 °/s） | `ω = raw / 16.4` |

数据区一次连续读 14 字节（温度 2 + 加速度 6 + 陀螺 6），避免两次事务之间被打断；
字节序为**大端 int16**。

### 1.3 初始化流程（`open()`）

1. `open(dev)` → 地址自动识别：依次试传入地址、0x68、0x69，`WHO_AM_I==0x47` 即命中，
   命中后把实际地址写回 `cfg_.addr`（后续读写都用它）；
2. **不做软复位**（原因见坑 1）；
3. 写 `BANK_SEL=0` → `PWR_MGMT0=0x0F` → `GYRO_CONFIG0=0x04` → `ACCEL_CONFIG0=0x24`；
4. **回读校验**：`PWR_MGMT0==0x0F`、`ACCEL_CONFIG0` 的 FS 位 == 0x20，否则报错返回，
   避免上层拿到"看起来正常"的假数据；
5. 失败时 `lastError()` 给出具体原因（接线/地址/回读不符）。

### 1.4 读写重试

`writeReg()` / `readRegs()` 各重试 **3 次、间隔 2 ms**：长线 I²C 偶发 NAK，
重试是幂等的（配置写入）且能扛住偶发干扰。`read()` 失败后由上层计数，50 次连续失败
触发关闭 + 5 s 后重连。

## 2. `imu_pitch.cpp` —— 俯仰融合

```cpp
// 加速度角：只投影到枪管轴
acc = asin(clamp(u · a / ‖a‖)) × 180/π;  // u = accel_axis
// 角速度：扣零偏、可选翻符号
rate = gyro[gyro_axis] − gyro_bias_dps;
// 可信判定
confident = (|‖a‖−1| ≤ accel_tol_g) && (|rate| ≤ accel_gate_dps);
// 互补滤波
θ += rate·dt;
if (confident && |wrap(acc − θ)| ≤ inn_tol_deg) θ += (1−alpha)·wrap(acc − θ);
```

- 第一次收到有效帧时用加速度角**播种**（`seeded_`）；
- `zeroHere()` 把当前 `θ` 记为 0°（`pitchDeg()` 返回 `wrap(θ − zero)`）；
- `wrap180()` 把所有角度折到 (−180, 180]。

## 3. 关键坑（都是实机踩出来的）

1. **软复位会让芯片 NAK 一段时间**：写完 `DEVICE_CONFIG.RESET` 后，紧接写 `PWR_MGMT0`
   会 `Remote I/O error`，还会把总线挂住、后续读全失败。所以驱动**不做软复位**：
   上电默认寄存器是确定的，直接配置 + 回读校验即可。
2. **地址会跳**：模块 AP_AD0 悬空时，I²C 地址在 0x68/0x69 之间随机跳（实测一次在 0x69、
   一次在 0x68）。驱动 `open()` 自动试两个地址；运行中跳变表现为读失败 → 5 s 重连。
3. **`i2c_msg` / `I2C_M_RD` 的头文件**：本机 `<linux/i2c-dev.h>` 不带这两个定义，
   必须额外 `#include <linux/i2c.h>`，否则编译报 incomplete type。
4. **加速度计会被线性加速度污染**：0.3 g 沿枪管在 0° 姿态下会让加速度角偏 17°，
   仅靠 `|‖a‖−1|` 门限（4.4%）拦不住，所以必须叠加创新门限。
5. **陀螺零偏**：Z 轴实测 +0.44 ~ +0.45 °/s，不扣的话动态每秒漂半度；由 main 开机
   静止 2 s 自动标定（σ>1.5 °/s 视为有运动、重新标定）。

## 4. 与主循环的集成（`src/main.cpp`）

| 位置 | 做了什么 |
|---|---|
| 启动 | `--imu` 打开设备（地址自动识别），`--imu-log` 打开逐帧记录 |
| 每拍读取 | 先做**零偏标定**（2 s 窗口、安静样本、σ<1.5 否则重来），完成后同一拍起 `imu_pitch.update(sample, dt)` |
| 抬升到位 | `PitchSession` 置 `imu_zero_req` → 主循环 `zeroHere()`，IMU 0° = 本次抬升到位姿态 |
| 主动阻尼 | `PitchSession` 的 `applyDamping()`：`|pc 速率| < 2 °/s` 时 `rate -= damp_k × ω_imu` |
| 打滑检测 | `PitchSession` 顶部：0.5 s 窗口累计 `|Δest|` 与 `|ω_imu|·dt`，比值 >1.6 判打滑（`Raising` 中止、`Active` 警告；`--pitch-abs` 下关闭） |
| 记录 | `--imu-log` 逐帧写：`t / IMU 俯仰 / 融合角速度 / 原始 gz / 编码器 est / 状态位 / pitch rpm / yaw est / yaw rpm` |

> 注意：抬升目标**不**由 IMU 决定（启动自检 10°，客户端首次 40° 定零、之后"回到 0°"；退出时 pitch 失能放松）；
> IMU 只在到位时同步清零，并用于阻尼 / 绝对保持 / 打滑检测。

## 5. 验证

- 纯软件：`./build/gimbal --selftest` 的
  - `[12] IMU 俯仰融合`：静态精度、动态跟踪、线性加速度门限；
  - `[13] 绝对仰角保持`：FakeTransport + 手构造 IMU 角度，验证底盘倾斜补偿；
  - `[11] 起停手感`：指令流台阶（每帧 ≤1 RPM、单调）；
- 真机：`./build/gimbal --imu-probe --imu /dev/i2c-1` 打印 WHO_AM_I 与逐帧角度；
- 端到端（2026-11-01 实测）：启动自检 10° → 客户端抬 40° 定 0° → 控制 → 断流放下 40° → 退出放松电机；
  三轮会话验证"回到已建立的 0°"，零点不再爬升。
- 打滑案例（2026-11-01）：联轴器打滑时电机 10 RPM / 编码器 65 °/s / IMU 25 °/s，
  检测在 est≈17° 处中止并锁死。
