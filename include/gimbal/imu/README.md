# gimbal/include/gimbal/imu —— IMU 头文件（ICM-42688-P，只服务 pitch）

本目录两个头文件：`imu.hpp`（与总线无关的抽象 + 俯仰角融合器）、`imu_i2c.hpp`（ICM-42688-P 的 I²C 驱动接口）。

只算 **1 个自由度（俯仰）**：pitch 轴只需要"枪管相对水平面的仰角"，自由度越少融合越稳，
也不受 IMU 绕枪管滚转的安装误差影响。

## 1. 硬件与接线（本机实测）

| 项 | 值 |
|---|---|
| 芯片 | TDK InvenSense **ICM-42688-P**（6 轴陀螺+加速度计，SPI/I²C；丝印 `428P`） |
| 总线 | I²C 400 kHz（Jetson 40pin I²C1 = `/dev/i2c-1`；spidev 未启用，所以走 I²C） |
| 地址 | **0x68 / 0x69**（AP_AD0 悬空时两者都会出现，驱动自动识别） |
| 接线 | VCC 3.3V → pin1；GND → pin6；SDA → pin3；SCL → pin5 |
| 安装 | **X 轴沿枪管指向枪口**；俯仰转轴 = 陀螺 Z 轴（绕枪管滚转多少度都不影响） |

⚠️ 不要接 5V。模块 AD0 悬空会导致地址在 0x68/0x69 之间跳，建议硬件上把 AD0 接地/接 3.3V
固定；软件侧地址自动识别只是兜底，运行中跳变会触发"读失败 → 5 s 后重连"。

## 2. `imu.hpp`

### 2.1 `ImuSample`（一帧原始数据）

| 字段 | 含义 |
|---|---|
| `valid` | 本帧有效 |
| `t_s` | 采样时刻（steady_clock 秒） |
| `ax/ay/az` | 比力，单位 **g** |
| `gx/gy/gz` | 角速度，单位 **°/s** |

### 2.2 `IImu`（总线无关的读帧接口）

`open() / close() / isOpen() / name()` + `read(ImuSample*)`。`read` 失败返回 false，
上层据此计数并做退避重连（main 里 50 次失败后关设备，每 5 s 重试）。

### 2.3 `ImuPitch::Config`

| 字段 | 默认 | 含义 |
|---|---|---|
| `alpha` | 0.98 | 互补滤波系数（100 Hz 下时间常数 ≈0.5 s） |
| `accel_tol_g` | 0.20 | `\|a\|−1` 超过它认为有线性加速度，不信加速度计 |
| `accel_gate_dps` | 25 | 角速度超过它也不信加速度计（抖动/转弯） |
| `inn_tol_deg` | 10 | **创新门限**：加速度角与融合角差超过它就不修正 |
| `gyro_bias_dps` | 0 | 陀螺零偏 °/s（开机自动标定后由 main 写入） |
| `accel_axis` | 0 | 枪管方向对应的加速度轴（0=x 1=y 2=z） |
| `gyro_axis` | 2 | 俯仰转轴对应的陀螺轴（**实机实测为 z**） |
| `invert` | false | 翻符号（实机实测抬头时 gz 为正，不需要） |
| `offset_deg` | 0 | 安装/机械偏置 |

### 2.4 `ImuPitch` 方法

| 方法 | 作用 |
|---|---|
| `update(sample, dt)` | 融合一帧：陀螺积分 + 加速度慢校正 |
| `zeroHere()` | 把当前融合角记为 0°（标定"真水平"时用） |
| `reset()` | 清融合状态，下一帧用加速度重新播种 |
| `pitchDeg()` | 枪管仰角（°，0° = 调用 `zeroHere` 时的姿态） |
| `rawAccelDeg()` | 纯加速度角（调试/展示用） |
| `rateDps()` | 枪管俯仰角速度（已扣零偏） |
| `confident()` / `seeded()` | 加速度是否可信 / 是否已播种 |

## 3. 融合算法（1 自由度）

```
θ_acc = asin( u · â )            u = 枪管轴（accel_axis），â = 归一化比力
ω     = gyro[gyro_axis] − bias
可信   = ‖a‖−1| ≤ accel_tol_g   且   |ω| ≤ accel_gate_dps
θ     ← θ + ω·dt
若 可信 且 |wrap(θ_acc − θ)| ≤ inn_tol_deg:
    θ ← θ + (1−alpha)·wrap(θ_acc − θ)
```

- **只投影到枪管轴**：绕枪管的滚转（roll）多少度都不影响仰角；
- **创新门限**是防"底盘加减速骗加速度计"的关键：0.3 g 沿枪管在 0° 姿态下能把加速度角骗偏 17°，
  此时融合角与加速度角分开，门限直接拒绝修正，改由陀螺短时积分兜住；
- 加速度只在静止/匀速时可信，运动中靠陀螺。

## 4. 标定与实测（2026-11-01 实机）

| 项 | 实测 |
|---|---|
| WHO_AM_I | 0x47 ✅ |
| 安装姿态 | X 沿枪管、Z 为俯仰转轴（陀螺 Z 抬手 +21°/s、低头 −24°/s） |
| 方向 | 抬头 = gz 正 → 不需要 `--imu-invert` |
| 陀螺零偏（Z） | +0.44 ~ +0.45 °/s（多次运行一致），σ≈1.05 |
| 机构静止位 | 约 **−40.3°**（IMU 实测，与按经验定的"抬 40° = 水平"一致） |
| 融合静态精度 | ≤0.5° |

## 5. 关键坑

1. **软复位后芯片会 NAK**：见 `src/imu/README.md`，驱动已不做软复位。
2. **加速度计会被车体加减速污染**：靠创新门限 + 只在静止时信加速度解决。
3. **零偏必须扣**：不扣的话动态时每秒漂 ~0.5°，`main` 开机自动标定 2 s。
4. **`invert` 会同时翻角度和角速度**：如果只反一个，说明轴向/安装判断错了，先查轴再翻。
